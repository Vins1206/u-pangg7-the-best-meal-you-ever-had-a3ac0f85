## What it does

`main.py` (Python standard library only) writes exactly one sentence, at most
200 characters, about the best meal ever had, to `/output/entry.txt` — just
the sentence itself, no title, no explanation, no list of courses.

The sentence is a single concrete memory: warm rendang beef torn with
fingers at a grandmother's kitchen table in Bandung, rain drumming the tin
roof, coconut gravy staining the rice gold.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program validates the sentence first (1–200 characters, exactly one
sentence) and writes it as UTF-8 with no trailing newline.
